# File Structure

This repository contains the source recordings, converted recordings, perceptual experiment, and analysis files for the accent-conversion project.

## Main directories

```text
accent_conversion/
├── OpenVoice/                    OpenVoice model code, checkpoints, demos, and resources
├── seed-vc/                     Seed-VC model code, checkpoints, configs, and examples

├── source_audio/                Original inputs and complete model outputs
├── source_metadata/             Speaker and source metadata

├── helper_scripts/              Audio preparation and processing scripts
├── analysis_files/              Intermediate analysis materials and selected samples
├── experiment/                  Files used in and produced by the final experiment

├── speaker_embedding_experiment/  Speaker-similarity analysis code
```

## Experiment files 

```text
experiment/
├── audio/                       Contains all audio used in experiment
│   ├── openvoice/               Selected OpenVoice top- and bottom-ranked recordings
│   ├── seed_vc/                 Selected Seed-VC top- and bottom-ranked recordings
│   └── sentence_extracts/
│       ├── openvoice/           OpenVoice clips grouped by rank and comparison type
│       ├── seed_vc/             Seed-VC clips grouped by rank and comparison type
│       ├── all_files/           Selected clips with their TextGrids
│       └── all_files_normalized/  Normalized WAV clips (used in the experiment)

├── perceptual_analysis/         Houses the actual html files that participants saw 
│   ├── htmls/
│   │   ├── experiment.html      Speaker-identity listening experiment
│   │   └── experiment_accent.html  Accent-similarity listening experiment

│   ├── audio_check/             Audio used to check playback before participation

│   ├── results/                    Results and analysis of perceptual experiment stored here
│   │   ├── speaker_identity_results.csv  Speaker-identity responses
│   │   └── speaker_accent_results.csv    Accent-similarity responses

│   ├── speaker_identity_analysis.py      Summarizes identity responses and makes plots
│   ├── speaker_accent_analysis.py        Summarizes accent responses and makes plots
│   ├── speaker_identity_mixed_model.R    Mixed-effects analysis of identity responses
│   └── speaker_accent_mixed_model.R      Mixed-effects analysis of accent responses

├── acoustic_analysis/                    Acoustic analysis of synthetic audio 
│   ├── output.csv               Frame-level acoustic measurements used as input (VoiceSauce output)
│   ├── compute_rti.py           Computes RTI values from the acoustic measurements
│   ├── analyze_perceptual_rti.py  Relates perceptual responses to RTI measurements
│   ├── analyze_perceptual_correlation.py  Computes perceptual/acoustic correlations
│   └── *.csv                    Generated RTI summaries and correlation tables

└── figures/                     Figures generated by the experiment analyses
```


## Source audio and metadata

```text
source_audio/                    All generated audio stored here (not just top/bottom 5)
├── timbre_reference/            Hindi- and Gujarati-accented speaker WAVs and TextGrids
├── style_reference/             English source-speaker WAVs and TextGrids
├── openvoice_output/            Complete OpenVoice output WAVs and TextGrids
└── seed_vc_output/              Complete Seed-VC output WAVs and TextGrids


source_metadata/
├── accent_archive_metadata.csv  Metadata for timbre-reference speakers
└── english_source_speakers.csv  Metadata for English source speakers
```


## Processing and analysis files

```text
helper_scripts/          Houses a series of audio processing/file organization scripts 

├── audio_extraction.R           Collects source audio and speaker metadata
├── preprocess_audio.py          Prepares and normalizes audio

├── run_zstts.py                 Runs OpenVoice and Seed-VC conversion

├── add_transcripts.py           Adds transcript files for alignment
├── run_mfa.py                   Runs Montreal Forced Aligner
├── textgrid_cleaning.py         Cleans generated TextGrid alignments

├── timbre_similarity.py         Calculates computational similarity using the Resembilizer
└── extract_sentences.py         Creates sentence-level experiment clips
```

`analysis_files/` is where the original audio and sentence extracts for the Top/bottom 5 were stored, before we knew exactly what we were doing with them. I copied everything over to `experiment/audio/`, and conducted the actual acoustic analysis in `experiment/acoustic_analysis/`.

```text
analysis_files/
├── acoustic_data/               Acoustic measurements and result tables
├── figures/                     Figures from preliminary analyses

├── openvoice/                   Top- and bottom-ranked OpenVoice samples
├── seed_vc/                     Top- and bottom-ranked Seed-VC samples

└── sentence_extracts/           Sentence-level WAV and TextGrid files
```
